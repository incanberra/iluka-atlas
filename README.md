# Iluka Atlas

An independent, source-linked interactive guide to Iluka Resources, based on the 2025 annual report and company releases available through 30 October 2026. Published with GitHub Pages from `site/`.

Run locally with `python -m http.server --directory site 8000`. The operations map is generated with `python scripts/map.py` using Natural Earth geometry. Chart.js and Open Sans are vendored with their licences. Figures and assumptions are documented on the site. This project is not affiliated with Iluka and is not financial advice.
